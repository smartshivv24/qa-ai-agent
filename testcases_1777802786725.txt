**Test Cases for Payment Checkout Page with Credit Card and UPI Options**

### Test Case 1: Successful Credit Card Payment

* **Test Case ID:** PC-001
* **Description:** Verify that the user can successfully make a payment using a valid credit card.
* **Preconditions:** 
    + The user has logged in to their account.
    + The payment checkout page is opened.
    + The user has a valid credit card with sufficient balance.
* **Steps:**
    1. User enters their credit card details (card number, expiration date, CVV, etc.).
    2. User selects the credit card payment option.
    3. User confirms the payment details.
    4. The system processes the payment.
* **Expected Result:** The payment is successful, and the user is redirected to the confirmation page or the payment summary page.

### Test Case 2: Unsuccessful Credit Card Payment

* **Test Case ID:** PC-002
* **Description:** Verify that the user cannot make a payment using an invalid or expired credit card.
* **Preconditions:** 
    + The user has logged in to their account.
    + The payment checkout page is opened.
    + The user has an invalid or expired credit card.
* **Steps:**
    1. User enters their credit card details (card number, expiration date, CVV, etc.).
    2. User selects the credit card payment option.
    3. User confirms the payment details.
    4. The system rejects the payment.
* **Expected Result:** The system displays an error message indicating that the payment failed due to invalid or expired credit card.
